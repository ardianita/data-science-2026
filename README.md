## Cara Menjalankan Notebook di Google Colab

1. Buka file notebook (`.ipynb`) pada repository GitHub.
2. Klik tombol **Open in Colab**.
3. Notebook akan terbuka secara otomatis di Google Colab.
4. Jalankan setiap cell secara berurutan dengan menekan tombol **▶ Run**.
5. Pastikan seluruh cell dijalankan dari atas ke bawah agar tidak terjadi error akibat dependensi yang belum dimuat.
